# hpak

A Horizon OS package manager

Features:
 - Full package management with a clean console-first interface
   - Mouse mode, touch and various other functions are supported
 - Repos - use different repos for different packages
   - The only included repo is the Ouncebrew repo, which contains basic homebrew
 - Dependencies - Packages can depend upon others, even if they are from different repos
 - App images and video - View data and gameplay of apps and games
